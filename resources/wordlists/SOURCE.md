# EFF Long Wordlist

Source: https://www.eff.org/files/2016/07/18/eff_large_wordlist.txt
Description: https://www.eff.org/dice
Author: Electronic Frontier Foundation; wordlist created by Joseph Bonneau.
Retrieved: 2026-10-12 (Asia/Taipei).
Original SHA-256: addd35536511597a02fa0a9ff1e5284677b8883b83e986e43f15a3db996b903e
Entries: 7,776, original dice-code order, unique words, maximum word length 9.
Four original entries include hyphens: drop-down, felt-tip, t-shirt, yo-yo.
The downloaded original bytes are unchanged. Runtime parsing removes dice codes only;
it does not filter, translate, reorder, or alter words.
